# 🧐 06-reviews: 架构设计评审与审计检视报告

本目录收录 Code-Shield 系统核心架构演进方案、技术设计草案的前置设计评审（Design Review）、架构合规审计与技术可行性把关意见。

---

## 🎯 目录定位与评审规程

1. **职责正交**：
   * `02-architecture/`：现行系统核心架构与领域设计规范（单一真实源 SSOT）；
   * `03-rfcs/`：重大架构选型决策记录（ADR）与立项提案；
   * `04-reports/`：上线后的实测基准（Benchmarks）、故障复盘（Post-mortems）与发版里程碑；
   * **`06-reviews/`**：**方案实施前**的深度技术评审、副作用评估、数据影响分析与准入把关。
2. **评审状态流转**：
   * `Draft (评审中)` $\to$ `Request Changes (需重大修订，阻断落地)` $\to$ `Approved (评审通过，准予进入开发)`。
