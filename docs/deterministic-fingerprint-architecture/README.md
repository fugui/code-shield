# CodeShield 确定性源码指纹与抗抖动增量生命周期架构 (Deterministic Fingerprint Architecture)

## 📌 架构专题简介
本目录收录 CodeShield 针对大模型代码扫描场景下**“缺陷指纹漂移”、“大面积假修复误报（CLOSED / RESOLVED）”**以及**“相同缺陷重复新建（NEW / REOPENED）”**等业界痛点难题的系统级架构设计与落地规范。

核心设计思想是：**“缺陷的唯一身份（指纹）必须源于客观物理源码的确定性，而非大模型主观文本的随机性；缺陷生命周期的终结（RESOLVED）必须源于物理代码版本的真实变更，而非大模型单次推理的概率漏报。”**

## 🎯 核心解决的技术痛点

1. **同文件多缺陷指纹碰撞退化**：彻底解决 `task_runner.go` 丢失 `trigger_line` 与局部代码片段无法提取 `scope_symbol` 导致退化为文件名指纹的问题；
2. **大模型文本与分类漂移**：大模型仅负责提供定位坐标与描述性文本，服务端通过受控白名单字典与物理源码解析计算确定性特征；
3. **假修复高频震荡终结**：引入物理文件内容 Hash 变更守卫与连续未命中计数（`missed_count`）机制，杜绝单次大模型概率漏报导致批量标记 RESOLVED；
4. **生命周期跨版本平滑继承与智能自愈**：通过 L1/L2/L3 阶梯容错与 L4 单文件批量集合语义对齐，确保在复杂代码重构、变量改名时历史人工反馈（误报/不修复）100% 稳定继承并实现指纹自愈。
